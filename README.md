# Guitar wiring options — 2× humbucker, 1 volume, 1 tone, 1 selector

**→ [itaiche.github.io/guitar-wiring-options](https://itaiche.github.io/guitar-wiring-options/)**

Wiring design for a semi-hollow Les Paul-style build with two custom-wound PAF-class humbuckers,
limited to one volume, one tone and one pickup selector.

The recommendation: a 4-pole 5-way super switch, a push-pull volume that means one thing in every
detent, a plain tone pot, and an **RWRP-specified pickup pair** — ten voices, eight of them
hum-cancelling.
